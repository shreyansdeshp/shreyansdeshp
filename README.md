**[🛰️ LiDAR — Archaeological Site Detection](https://github.com/shreyansdeshp/LiDAR)**
`PyTorch` `ConvNeXt` `QGIS` `Rasterio`

Multimodal deep-learning pipeline fusing 1m LiDAR terrain data with Sentinel-2 imagery to detect archaeological sites across 226 km² of Ireland. `Python` `DualSPHysics` `Delft3D` `GEE`
